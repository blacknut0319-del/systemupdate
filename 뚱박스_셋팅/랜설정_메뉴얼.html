뚱박스 랜(IP) 설정 메뉴얼

뚱박스(Net 포트)를 PC에 연결할 때 필요한 한글 안내입니다.
아래 참고 그림은 제조사 원본(중국어)이지만, 파란 박스 한글 설명만 따라 하시면 됩니다.

뚱힐러에서: 상단 [장치] → 뚱박스 → [드라이버] · [IP설정] · [메뉴얼] 버튼으로 같은 작업을 할 수 있습니다.

박스 연결 (단일 PC)

게임기 포트(1번)와 Net 포트(2번) USB를 같은 PC에 연결합니다.

▶ 한글 안내: 왼쪽이 뚱박스 본체입니다. 1번(게임기 USB)과 2번(Net/네트워크 USB)을 PC에 꽂고, 키보드·마우스는 박스 앞면 포트에 연결하세요.

1단계 — Net 포트(2번) 랜 드라이버 설치

  1. Net 포트(2번) USB를 PC에 연결
  2. 가상 디스크(CD-ROM)가 뜨면 → 열기 → 설치 프로그램 실행
  3. 디스크가 안 뜨면 → 뚱힐러 [드라이버] 버튼 (WCHUSBNIC.EXE)
  4. 설치 후 PC 재부팅 권장
▶ 한글 안내: 새로 뜬 CD-ROM(가상 디스크)을 열고, 안의 설치 exe를 실행하세요. 글자가 중국어여도 설치(Install) 버튼만 누르면 됩니다. 안 뜨면 뚱힐러 [드라이버]를 쓰세요.
주의: 드라이버는 Net USB를 꽂은 그 PC에 설치하세요. 다른 PC에만 설치하고 선만 옮기면 안 됩니다.

2단계 — 뚱박스 전용 이더넷 IP 변경 (가장 중요!)

뚱박스 LCD에 나온 IP(예: 192.168.2.188)와 PC가 같은 대역이어야 합니다.
인터넷 쓰는 Wi-Fi·기존 이더넷은 절대 건드리지 마세요. USB로 새로 생긴 어댑터만 수정합니다.

① 제어판 → 네트워크 및 공유 센터

▶ 한글 안내: Windows 검색에서 「제어판」 실행 → 「네트워크 및 공유 센터」를 클릭하세요. (그림은 중국어 Windows 예시)

② 어댑터 설정 변경 → 뚱박스 전용 이더넷

▶ 한글 안내: 왼쪽 「어댑터 설정 변경」 → 목록에서 새로 생긴 이더넷(USB Ethernet, WCH, 이더넷 2 등)을 찾으세요. Wi-Fi·인터넷용 어댑터는 선택하지 마세요.

③ IPv4 속성 → IP 수동 입력

▶ 한글 안내: 뚱박스용 어댑터 우클릭 → 속성 → 목록에서 「인터넷 프로토콜 버전 4(TCP/IPv4)」 선택 → 속성 버튼.
▶ 한글 안내: 「다음 IP 주소 사용」 선택 후 아래처럼 입력 → 확인.
IP 주소192.168.2.100 (뚱박스 188과 다른 번호)
서브넷 마스크255.255.255.0
게이트웨이 / DNS비워 둠
뚱박스 LCD IP가 188이 아니면, 같은 192.168.2.x 대역에서 박스와 겹치지 않는 번호(예: .100)를 쓰면 됩니다.

3단계 — ping으로 통신 확인

  1. Win + R → cmd → Enter
  2. 뚱박스 LCD에서 IP 확인 (예: 192.168.2.188)
  3. 입력: ping 192.168.2.188 (ping과 IP 사이 공백 필수)
▶ 한글 안내: Win+R → cmd 입력 → 확인. 검은 명령 프롬프트 창이 열립니다.
▶ 한글 안내: ping 뚱박스IP 입력 후 Enter. 예: ping 192.168.2.188
▶ 한글 안내: 「응답=…」 또는 Reply from … 이 보이면 연결 OK입니다. 시간 초과면 1~2단계를 다시 확인하세요.

4단계 — 뚱힐러에 뚱박스 정보 입력

뚱박스 LCD에 표시된 값을 정확히 입력하세요 (하나라도 틀리면 연결 불가):

  • IP — 예: 192.168.2.188
  • 포트 — 예: 8808 (박스마다 다를 수 있음)
  • UUID — MAC 칸에 박스 화면 UUID 입력 (박스마다 다름)
▶ 한글 안내: 그림은 제조사 설정 프로그램(중국어) 예시입니다. 뚱힐러에서는 상단 IP / 포트 / UUID 입력칸에 같은 숫자를 넣고 설정저장 후 시작하세요. 중국어 프로그램을 열 필요 없습니다.

자주 묻는 문제

  • IP 바꿨더니 인터넷 끊김 → Wi-Fi/본래 이더넷을 잘못 수정함. 뚱박스 Net 전용 새 어댑터만 변경.
  • 드라이버 설치해도 ping 안 됨 → Net 포트(2번) 선, 어댑터 IP, 뚱박스 전원·LCD IP 확인.
  • ping은 되는데 뚱힐러만 안 됨 → IP/포트/UUID 일치 여부, 다른 프로그램이 뚱박스 점유 중인지 확인.

참고 그림 출처: 제조사 공식 매뉴얼 (중국어 원본). 안내 문구는 뚱힐러용 한글입니다.
