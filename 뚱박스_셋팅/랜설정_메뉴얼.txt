================================================================================
  뚱박스 랜(IP) 설정 메뉴얼 — 뚱힐러용 한글 안내
================================================================================

■ 이 메뉴얼이 필요한 경우
  - 뚱박스 Net 포트(2번, 네트워크 USB)를 PC에 꽂았는데 연결이 안 될 때
  - ping 192.168.2.188 이 안 될 때
  - 뚱힐러에서 "뚱박스 연결실패" / 응답없음이 나올 때

■ 뚱힐러에서 바로 쓰기
  상단 [장치] → 뚱박스 선택
    [드라이버]  — 랜 드라이버 설치
    [IP설정]    — 한글 IP 설정 안내 창
    [메뉴얼]    — 이 문서(HTML) 열기

■ 박스 연결 구조 (단일 PC)
  [게임기 포트 1번] ──USB──→ PC  (키/마우스 신호가 게임으로 전달)
  [네트워크 포트 2번] ──USB──→ PC  (뚱힐러가 뚱박스를 제어하는 통신)
  [키보드 포트] ←── 실제 키보드
  [마우스 포트] ←── 실제 마우스

  ※ 게임기 포트(1번) USB를 안 꽂으면 키보드만 되고 마우스가 안 될 수 있음
  ※ 키보드·마우스는 각각 다른 포트에 꽂아야 동시 사용 가능

  [참고 그림 03.png]
  ▶ 한글: 1번·2번 USB를 PC에 꽂고, 키보드·마우스는 박스 앞면에 연결

================================================================================
  1단계 — Net 포트(2번) 랜 드라이버 설치
================================================================================

  (1) Net 포트(2번) USB를 PC에 연결

  (2) 방법 A — 가상 디스크가 뜨는 경우
      · 내 PC에 새 디스크(CD-ROM 형태)가 나타남
      · 디스크를 열고 안의 exe를 실행해 설치 (중국어여도 설치 버튼만 누르면 됨)

  (3) 방법 B — 디스크가 안 뜨는 경우 (대부분 노트북)
      · 뚱힐러 → [드라이버] 버튼
      · 또는 WCHUSBNIC.EXE 실행
      · 설치 후 PC 재부팅 권장

  [참고 그림 1714548779556.png]
  ▶ 한글: 가상 CD-ROM 열기 → 설치 exe 실행. 안 되면 뚱힐러 [드라이버]

  ※ 드라이버는 "Net 포트 USB를 꽂은 그 PC"에 설치해야 함

================================================================================
  2단계 — 뚱박스 전용 이더넷 IP 변경 (가장 중요!)
================================================================================

  뚱박스 LCD IP(예: 192.168.2.188)와 PC가 같은 대역이어야 합니다.
  PC IP는 뚱박스와 겹치지 않는 숫자로 설정합니다.

  (1) Windows 키 → "제어판" → [네트워크 및 공유 센터]
  [참고 그림 04.png]
  ▶ 한글: 제어판 → 네트워크 및 공유 센터

  (2) [어댑터 설정 변경]
  [참고 그림 1714548926047.png]
  ▶ 한글: 새로 생긴 USB 이더넷만 선택 (Wi-Fi/인터넷용 X)

  (3) 우클릭 → [속성] → IPv4 → [속성]
  [참고 그림 1714548993390.png]
  ▶ 한글: TCP/IPv4 선택 → 속성

  (4) [다음 IP 주소 사용]:
        IP:       192.168.2.100  (뚱박스와 다른 번호)
        서브넷:   255.255.255.0
        게이트웨이·DNS: 비워둠
  [참고 그림 1714549022434.png]
  ▶ 한글: IP 수동 입력 후 확인

================================================================================
  3단계 — 통신 확인 (ping)
================================================================================

  (1) Win + R → cmd → Enter
  [참고 그림 1714549075489.png]
  ▶ 한글: cmd 실행

  (2) ping 192.168.2.188  (뚱박스 LCD IP)
  [참고 그림 1714549139898.png]
  ▶ 한글: ping + 뚱박스 IP 입력

  (3) "응답=..." / Reply from ... → OK
  [참고 그림 1762505960134.png]
  ▶ 한글: 응답 오면 성공, 시간 초과면 1~2단계 재확인

================================================================================
  4단계 — 뚱힐러에 입력
================================================================================

  뚱박스 LCD 값을 정확히 입력:

    IP   : 192.168.2.188  (박스 화면)
    포트 : 8808           (박스 화면)
    UUID : (박스 화면, MAC 칸에 입력)

  뚱힐러 상단 IP/포트/UUID → [설정저장] → Insert 시작

  [참고 그림 1762508652548.png]
  ▶ 한글: 제조사 중국어 프로그램 예시. 뚱힐러 입력칸에 같은 값 넣으면 됨

================================================================================
  자주 묻는 문제
================================================================================

  Q. IP 바꿨더니 인터넷이 안 됨
  A. Wi-Fi/본래 이더넷을 잘못 수정. 뚱박스 Net 전용 어댑터만 변경.

  Q. 드라이버 설치했는데도 ping 안 됨
  A. Net 포트 선, 어댑터 IP, 뚱박스 전원·LCD IP 확인.

  Q. ping은 되는데 뚱힐러만 안 됨
  A. IP/포트/UUID 일치, 다른 프로그램이 뚱박스 점유 중인지 확인.
