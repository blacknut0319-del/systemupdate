뚱박스 설정도구 — 실시간 한글 통역

옆에 뜬 중국어 프로그램(kmboxNet) 보면서 이 창만 보세요. 뚱힐러만 쓸 거면 IP/포트/UUID는 뚱힐러 입력칸에 넣으면 됩니다.
① 가장 먼저 할 일
중국어 창 왼쪽 위 连接盒子 = 「뚱박스 연결」 버튼 클릭
IP / Port / UUID는 뚱박스 LCD 화면 숫자 그대로 입력 (틀리면 연결 안 됨)
② 뚱힐러 사용자 필수
禁用Bypass 체크 = Bypass 끄기(KM 모드) — 뚱힐러는 이 상태여야 합니다.
启用Bypass = Bypass 켜기 — 초보는 건드리지 마세요.

뚱힐러만 쓸 때 (설정도구 최소 사용)

1. [드라이버] 설치 → 재부팅
2. PC 랜 IP 맞추기 (메뉴얼 참고)
3. ping 뚱박스IP 성공 확인
4. 설정도구에서 连接盒子 한 번 + 禁用Bypass 체크
5. 뚱힐러에 IP/포트/UUID 입력 → 설정저장 → 시작

이 통역창은 뚱힐러/뚱박스 셋팅 패키지에 포함됩니다. exe 안 글자는 제조사 파일이라 한글로 바꿀 수 없고, 이 창으로 대신 안내합니다.
