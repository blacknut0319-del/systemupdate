# 뚱힐러 (파티/자힐·물약)

뚱힐러는 **예전부터 이 저장소 루트**에 배포되어 왔습니다.  
자동업데이트/설치 zip을 갑자기 옮기면 기존 사용자 exe가 깨질 수 있어, **루트 파일은 유지**합니다.

## 지금 쓰는 경로 (레거시)

| 용도 | 경로 |
|------|------|
| 펌웨어 HEX | `firmware/뚱힐러.hex` |
| 시작/설치 zip | 루트 `hp_start.zip`, `ddong_start.zip` 등 |
| 소스 작업 | 로컬 `Desktop\뚱힐러_github` |

## 앞으로

새 자동업데이트는 이 폴더에 `version.json`을 두고  
Release 에셋은 `뚱힐러` / `ddunghealer` 이름으로 올리는 쪽을 권장합니다.  
(기존 루트 zip은 호환용으로 남겨 둠)

> 뚱법사 펌업 버튼도 **같은** `firmware/뚱힐러.hex` 를 받습니다.
